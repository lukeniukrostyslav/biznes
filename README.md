# BUSINESS OS

**Private Freelancer & Agency Business Command Center**

Standalone local-first web application for freelancers, consultants and small agencies.

## Product direction

The product is designed as serious paid software, not a PDF, Notion template, prompt pack or course.

Core workflow:

**Lead -> Proposal -> Project -> Invoice -> Payment -> Profit -> Repeat**

Planned modules:
1. Sales Pipeline
2. Client CRM
3. Project Management
4. Pricing Engine
5. Proposal Builder
6. Scope & Profit Calculator
7. Invoice Builder
8. Follow-up System
9. Cashflow
10. Business Dashboard

## Commercial target

Initial positioning: premium one-time purchase.

Target price range: **$79-$99**.

## Runtime principles

- Local-first
- Modern browser
- No mandatory server or database
- No mandatory subscription
- Export/import backup
- Desktop + mobile responsive
- No Notion dependency
- No paid API required for the core product

## Supported languages

Exactly five launch languages:
- English (en) - primary commercial language
- Spanish (es)
- German (de)
- French (fr)
- Russian (ru) - mandatory

See `docs/LOCALIZATION.md` for the decision and rules.
