# B10.2 — End-to-End Relationship Integrity

The browser UI validation now matches the persistence-layer relationship integrity rules.

Validated chains:

- Proposal → Lead → Client
- Project → Proposal → Client
- Invoice → Project → Client
- Payment → Invoice → Client
- Expense → Project → Client

The UI now rejects mismatched client ownership when saving or importing records instead of allowing a structurally valid but semantically inconsistent lifecycle.
