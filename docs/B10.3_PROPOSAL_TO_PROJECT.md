# B10.3 — Proposal → Project Conversion

Implemented the first real lifecycle conversion in the BUSINESS OS UI.

## Workflow

Accepted/Won Proposal → Create Project → Project keeps:

- clientId
- proposalId
- proposal value as initial revenue
- proposal value as Fee budget
- Fixed Fee billing type
- next action and notes

## Safeguards

- Only Accepted/Won proposals can be converted.
- A proposal cannot create a duplicate project.
- A proposal must have a client.
- The new project passes relationship integrity validation before persistence.
- Conversion action is localized for EN/RU/ES/DE/FR.

## Competitive research

Bonsai currently supports creating a project from an estimate and can automate invoice creation when a proposal is accepted. This checkpoint deliberately implements the core Proposal → Project transition first, preserving BUSINESS OS's local-first architecture; invoice automation remains a separate controlled step.
