# PROFIT OS — PREMIUM DESIGN V1

## Design-first rule
The visual system is developed and approved before business functionality is layered onto it.

## Approval gate
The user must review the deployed visual prototype and explicitly approve the design. No functional implementation is considered final before design approval.

## Frozen-after-approval rule
After approval, the approved visual system becomes the baseline. Functions are added without arbitrarily redesigning screens. Any required new UI element must preserve the established visual language.

## Visual direction
- Premium B2B finance/productivity product
- Calm, precise, trustworthy
- Dark navigation + bright workspace
- Strong typographic hierarchy
- Restrained blue accent
- High information density without visual clutter
- Rounded cards, subtle borders, minimal shadows
- Desktop-first with deliberate mobile adaptation

## Design-only behavior
Navigation between all V1 pages is available in the prototype so the complete visual flow can be inspected. Buttons show a design-preview message only. No business calculations, persistence, imports, exports or production localization are implemented in this design stage.

## Language
English is the canonical commercial design language for V1. Localization is implemented only after the design is approved, using the strict per-language resource rules in PROFIT_OS_MASTER_SPEC.md.
