# B09.1 — Active Pipeline Integrity

## Change

The pipeline engine now excludes opportunities with terminal statuses:

- Won
- Lost
- Closed
- Cancelled

Only active opportunities contribute to Pipeline and Weighted Pipeline.

## Why

A CRM pipeline should represent current potential business, not already-closed outcomes. This keeps Dashboard Pipeline aligned with the operational meaning of an active sales funnel.
