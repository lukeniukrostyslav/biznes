# B10.1 — Invoice Payment Status Engine

Implemented a reusable financial-engine function: `calculateInvoicePaymentStatus(invoice, payments, now)`.

It derives the invoice financial status from payments actually linked to the invoice, rather than trusting a potentially stale `invoice.paid` field.

Status flow remains:
- Draft
- Sent
- Partially Paid
- Paid
- Overdue
- Cancelled

This creates a single calculation path that can be reused by UI, dashboard and QA when the invoice lifecycle is wired end-to-end.
