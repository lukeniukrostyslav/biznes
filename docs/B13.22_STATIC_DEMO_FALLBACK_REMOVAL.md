# B13.22 — Static demo fallback removal

Дата: 2026-09-25

## Что сделано

Удалены статические demo-записи из первоначального HTML-render fallback для:
- Clients
- Invoices
- Proposals
- Payments
- Expenses
- Leads pipeline

Теперь эти области стартуют без встроенных demo-записей и заполняются только через local-first store и существующие render-функции.

## Цель

Исключить визуальный flash старых demo-данных до выполнения JavaScript-render и гарантировать, что пользовательский интерфейс не показывает вымышленные бизнес-данные как реальные.

## Ограничения

- Новые бизнес-функции не добавлялись.
- Financial Engine не изменялся.
- Persistence не изменялась.
- Browser/mobile runtime QA ещё не выполнена.
- Полный npm test не запускался.
