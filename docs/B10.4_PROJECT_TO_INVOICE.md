# B10.4 — Project → Invoice checkpoint

## Status
Implemented in `app/index.html`.

## Workflow
Project → Create Invoice

The action creates one local invoice linked to:
- `clientId` from the project
- `projectId` from the project

The generated invoice is seeded with:
- invoice name from project name
- status: Draft
- amount/value from project revenue, falling back to budget
- one line item with quantity 1 and the generated amount
- tax rate 0%
- no due date by default
- next action: Send invoice
- project notes copied to invoice notes

## Safeguards
- non-billable projects cannot create invoices
- duplicate invoice for the same project is blocked
- project must have a client
- project must have a positive billable amount
- generated invoice passes stored relationship validation before persistence

## Competitive research
Bonsai documents automatic invoice creation after proposal acceptance and package-to-line-item transfer. HoneyBook documents project-centered workflows and invoice configuration with taxes, discounts, service charges and payment schedules. BUSINESS OS uses the useful lifecycle principle while keeping the implementation local-first and transparent rather than copying the competitors.
