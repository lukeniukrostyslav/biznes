# Localization Strategy

## Locked launch languages

| Code | Language | Role |
|---|---|---|
| en | English | Primary commercial language |
| es | Spanish | Large international market |
| de | German | Strong online/business presence |
| fr | French | Large international and business-language audience |
| ru | Russian | Mandatory product language |

## Why these five

There is no reliable public dataset that directly ranks buyers of $79-$99 business software by language. Therefore we do not claim that any language is guaranteed to sell more.

The launch set combines audience size, international business reach, web presence, software relevance and practical localization scope. 2025 web-content data places English far ahead, with Spanish, German and French among the leading website languages; Russian also has substantial web presence. The World Bank's 2025 Digital Progress and Trends Report likewise shows English as dominant online and lists Russian, German, Chinese, Spanish and French among leading URL languages.

Reference research: World Bank Digital Progress and Trends Report 2025; We Are Social Global Digital Report 2026; Duolingo Language Report 2025.

## Product rule

All five languages are first-class UI localizations. Every user-visible string must come from locale dictionaries.

Required localized areas: navigation, dashboard, onboarding, forms, labels, placeholders, buttons, validation, calculators, pipeline statuses, proposal builder, invoice builder, empty states, success/error feedback, export/import, settings and mobile UI.

The selected language must persist locally and be included in portable project export.

## Translation quality

Machine translation can be a drafting aid, but final strings must be reviewed for natural business terminology in each language.

## Scope lock

No extra launch languages until the core product is complete and validated.
